# 本地密码管家（Chrome MV3 本地插件 · 免主密码 · 三形态）

一个**完全本地运行**的 Chrome 扩展：不上传应用商店、不连接任何服务器、不需要主密码，数据只存本机浏览器。

## 三种交互形态

| 形态 | 打开方式 | 特点 |
| --- | --- | --- |
| **① 悬浮弹窗** | 点工具栏图标 | 380px 窄宽、贴近网址栏，适合随手查一个账号；点条目后自动关窗 |
| **② 侧边栏** | 弹窗右上角「侧边栏」按钮；或在插件详情页把「在侧边栏中打开」设为默认 | 常驻浏览器右侧、满高度滚动列表，边浏览网页边查账号，不打断当前页面 |
| **③ 全屏标签页** | 弹窗 / 侧边栏右上角「全屏」按钮 | 独立标签页、居中 900px，宽屏自动双栏排布，适合整理、批量维护账号 |

> 三个形态共用同一套界面与逻辑（`app.js` + 同一份 CSS），数据实时共享 —— 在一个形态里改完，另一个形态刷新即见。

---

## 一、安装（本地加载，无需上架）

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本目录：`~/Desktop/本地密码管家`
5. 建议把插件图标拖到工具栏固定（点拼图图标 → 图钉）

> 代码有改动时，回到该页面点插件的「刷新」即可生效。侧边栏需要 Chrome 114 及以上。

## 二、使用

1. 点工具栏图标 → **直接进入列表**（没有解锁步骤）
2. 点「新增账号」，填写：网站域名 / 登录地址 / 账号 / 密码 / 备注
3. 保存后按域名自动分组显示；顶部搜索框输入即过滤

### 批量导入（文本）

点底部「**批量导入**」→ 粘贴文本 →「解析预览」→「导入 N 条」。

每行一条，字段顺序：**域名或网址、账号、密码、备注**（备注可省略）。支持这几种写法：

```
oa1.com	wang@oa1.com	你的密码	工作系统
https://mail.qq.com, me@qq.com, 你的密码, 私人邮箱
name,url,username,password,note      ← 浏览器导出的 CSV（表头行会自动跳过）
```

- 分隔符自动识别：Tab / 逗号 / 中文逗号 / 空格
- CSV 里带引号的字段（例如密码是 `"pa,ss"`）会正确解析
- 网址可省略协议与具体路径，只写域名即可（自动补 `https://`）
- 不含 `http(s)://` 的网址会先补协议再存，域名列留空时自动从网址推导
- **去重规则**：`域名 + 账号` 已存在则跳过，并在预览里报「重复跳过 N 条」；同一批内重复也跳过
- 缺密码、找不到域名/网址的行会单独报错，不影响其他行导入
- 预览最多列 50 条，密码不在预览中显示

## 三、核心行为

### 账号数据层
- 每条记录包含：网站域名、登录地址、账号、密码、自定义备注、创建/更新时间
- 按域名分组展示，支持**新增 / 编辑 / 删除**全量操作
- 记录以**明文**形式存放在本机 `chrome.storage.local`（Chrome 用户目录内），不做任何上传或同步

### 交互层
- 弹窗顶部是**实时搜索框**（输入即过滤），匹配优先级：**备注 → 域名 → 账号名**（其次登录地址）
- 点击搜索结果或分组中的任意账号条目 → 自动打开对应网站 → 自动填充表单 → 触发登录按钮
- 条目上还有「复制密码」和「编辑」快捷操作
- 右上角两个图标按钮负责形态切换：侧边栏 / 全屏

### 安全规则
- **全程无任何第三方服务器交互**，代码中没有 fetch / XHR / WebSocket / 外部脚本
- 权限：`storage`、`scripting`、`tabs`、`sidePanel`（侧边栏）+ `host_permissions: <all_urls>`（用于在任意站点执行填充）
- 存储使用 `chrome.storage.local`（纯本地磁盘），不使用 `sync`，不做任何外部同步

## 五、文件结构

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | MV3 清单：权限、弹窗入口、侧边栏入口 |
| `popup.html` / `sidepanel.html` / `app.html` | 三个形态的外壳页，仅 `data-ctx` 一行不同，界面由 `app.js` 注入 |
| `popup.css` | 全部样式（含三种形态各自的布局规则） |
| `app.js` | 核心逻辑：数据增删改、搜索、跳转登录、形态切换、一次性迁移 |
| `crypto.js` | **仅用于一次性迁移**：由旧主密码派生密钥、解密旧记录 |
| `background.js` | Service Worker：打开网页、注入脚本、填充表单并触发登录；安装时启用侧边栏 |
| `icons/` | 插件图标 |

## 六、从旧版本（主密码版）升级

旧版本用主密码派生的 AES-GCM 密钥加密记录。新版本不再需要主密码，但**旧密文只能用旧主密码解开**，所以提供了**一次性迁移**：

1. 刷新插件后打开弹窗，会自动弹出「迁移旧加密数据」对话框
2. 输入你上一次设置的主密码 → 点「迁移」
3. 插件会解密全部旧记录 → 以新格式（免密码）重写 → 删除旧的加密元数据
4. 之后打开插件**再也不会问主密码**，旧密文与旧密钥一起失效

> 迁移前会校验旧主密码是否正确；解密阶段任一条失败就整体中止，不会写出半截数据。
> 若旧主密码已忘记：旧数据本来也无法恢复，可在同一对话框点「清空旧数据」（需二次确认）后从零开始。

## 七、安全说明（请务必理解取舍）

去掉主密码后，数据不再加密，这带来了明确的权衡：

- 密码、备注以**明文**存于 Chrome 用户目录（`chrome.storage.local` 的 LevelDB 文件），**任何能读取你电脑或浏览器配置目录的程序/人都可以直接看到**（同机上其他账户、恶意软件、备份文件、取证工具等）。
- 换句话说：安全性从「靠主密码保护」降级为「靠操作系统账户与磁盘保护」。
- 建议配合：开机账户密码 + 屏幕锁定 + 磁盘加密（macOS 打开 FileVault、Windows 打开 BitLocker）。
- 插件本身仍然**不联网**：没有网络请求、没有统计、没有第三方 SDK，数据不会离开本机。

如果以后想回到「主密码保护」模式，说一声即可把加密层加回来（数据格式会再升级一次）。

## 八、已知限制与注意事项

- **自动填充依赖目标网站的表单结构**：本插件按「密码框 + 最近的账号输入框 + 登录按钮文案」启发式匹配。若某网站使用 iframe 登录页、验证码或二次验证，需手动输入；也可只打开页面再手动粘贴密码。
- 少数站点有反自动化脚本或自定义组件，可能需要手动点一次登录。
- `<all_urls>` 权限是「打开任意站点并自动填充表单」所必需的，这是本地自用插件的常见做法；若介意，可改为 `optional_host_permissions` 并在首次使用某站点时按需授权。
- **侧边栏按钮依赖用户手势**调用 `chrome.sidePanel.open()`；若被浏览器拒绝，改用「全屏打开」或在插件详情页把侧边栏设为默认。
- 数据保存在 Chrome 用户配置目录中，**清理浏览器数据 / 卸载插件会一并删除**，重要数据建议自行另存备份。

## 九、隐私声明

插件不采集、不上传、不共享任何信息。没有网络请求，没有统计代码，没有第三方 SDK。所有数据只在本机浏览器内读写。
