# 鸭力鸭 YaliYa · 桌面小黄鸭

高品质 3D 毛茸茸桌面小黄鸭原型 + 品牌视觉。**11 种状态**：空闲 / 奔跑 / 哭泣 / 打盹 / 庆祝 / 生气 / 冲刺 / 躺平 / 泡澡 / 装死 / 装正经。

## 🖥 桌宠版（macOS App）

`desktop/dist/鸭力鸭.app` —— 独立 .app，双击即用（也可双击项目里的 `启动小鸭.command`）。

| 功能 | 说明 |
| --- | --- |
| 常驻悬浮 | 菜单栏 🐤 托盘常驻；小鸭置顶、全屏 App 内也悬浮、三指切屏后原地在场（切屏扫过动画的 ~0.4s 内系统会剔除所有第三方窗口，属 macOS 机制） |
| 玩法 | 摸头（头顶缓慢划过→眯眼腮红+好感+0.2）、戳戳（出席吐槽/4 连点生气）、抱飞（快拖快甩→惯性滑行+撞边回弹+落地平衡眩晕）、隐藏→拜拜小跑退场、唤回→反向小跑归位压弹 |
| 养成 | 饱食度每小时 -8%（<30% 自讨食），托盘「喂玉米粒」回饱+好感+2；好感解锁皮肤：10 奶白 / 25 烤面包 / 45 薄荷 / 70 晴空 / 100 樱花 / 135 墨玉鸭 |
| 交互 | 拖拽换位（自动记忆），空白处鼠标穿透，右键完整菜单，老板键 `Ctrl+Option+B` |
| 自启 | 打包版默认写入登录项（菜单「开机自启」可关） |

尺寸 7 档：文件夹大小 / 迷你 / 超小 / 小 / 中 / 大 / 超大（托盘 ▸ 尺寸）。

## 网页完整体验版运行

**方式一（最简单）**：双击项目里的 `启动小鸭.command`（打包版存在时直接启动桌宠）。

**方式二（手动）**：
```bash
cd fluffy-duck
python3 -m http.server 8814
# 浏览器打开 http://localhost:8814/app.html
```

> 必须通过 http 访问（ES Module 资源不能从 file:// 加载）

## 自动流转

睡觉是挂机送的：空闲 3 分钟无操作 → 打盹；打盹 15 分钟仍被冷落 → 装死。
奔跑 45s / 冲刺 20s → 躺平（过劳）；庆祝 9s / 唱歌 14s / 生气 6.5s / 装正经 30s → 自回空闲。
系统电量 <20% 且未充电：空闲和打盹时无精打采（垂头缩体）。

## 技术要点

- **毛发**：壳层法（Shell Fur）——本体几何体沿法线膨胀出 20+ 层壳，壳层片元用 3D value noise + `discard` 做出绒丝，层间少量偏移制造绒毛碎感，重力下垂 + 根深尖浅配色
- **状态动画**：11 套程序化姿态函数（`STATE_POSE`）按权重（指数趋近）交叉淡化，加权求和进「全零姿态累加器」（`blankPose`），任何状态切换都无跳变；道具（浴缸/喷焰/眼镜/书）与表情粒子（Zzz/蒸汽/彩纸/泡泡/汗滴）随权重淡入淡出
- **哭泣眼泪**：InstancedMesh 泪珠，从眼角生成、挂在颊外滑落（`frustumCulled` 必须关掉，实例包围球不反映实例位置）
- **闭眼线**：两段半环 torus 当「眼皮」，按 `closeness = (0.32 - blinkScale*eyeOpen)/0.32` 缩放显隐，眨眼/睡觉/打盹时自然合眼
- `window.__duck` / `window.__tick` / `window.__capture(state, name)` 是调试句柄，可用于后续无窗口环境的自动化检查
